Mic Drop needs to be running

This extension keeps Google Meet in sync with Mic Drop on your Mac, but it can’t find Mic Drop right now.

  • Don’t have Mic Drop yet? Get it for free on the Mac App Store.
  • Already installed? Make sure Mic Drop is open; you’ll see its icon in your menu bar.
  • Still not working? Update Mic Drop to the latest version; older versions can’t connect to this extension.

You’re all set

Mic Drop is connected. Google Meet will now stay in sync with Mic Drop; you can close this tab.
